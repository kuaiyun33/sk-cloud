# 迁移、修复、安全与远端

## 变更流程

1. 改代码前确认目标文件属于哪一层。
2. 改共享能力前搜索调用方，确认影响范围。
3. 改字段、状态、字典、配置时，同步检查模型、验证器、队列、计划任务、路由、中间件。
4. 改目录或命名空间后检查自动加载、路由加载、配置引用和调用方。
5. 同一问题多处改时，先统一规则再批量适配。
6. 临时需求先放最窄业务位置，稳定复用后再上沉。
7. 完成后搜索旧命名、旧目录、旧字段兼容入口是否残留。

## 迁移

先识别功能意图，再按新目录和新字段重写，不直接复制旧结构。保留业务能力，抛弃旧命名、旧兼容入口、旧目录习惯和旧自定义风格。

迁移前判断新系统是否已有同类能力；有则合并，不新增平行实现。表只迁当前实际用到的结构和关联。

旧通用能力先判断属于 `foundation`、`resource`、`workers` 还是模型，不按旧 `extend`、`support`、`process` 原样照搬。字段语义不清时先查表结构和调用点，再决定 casts、默认值和状态判断。

不为「以后可能用到」提前搬大块代码；没有明确调用方的能力先不落地。不为「看起来更高级」过度拆层。

## Bug 修复

以根因为目标，不以压住当前报错为目标。禁止只针对当前输入、当前页面、当前日志写临时适配。禁止猜测式修复。

修复前收集：报错、调用入口、请求参数、库里实际数据、配置值、日志、旧项目对应逻辑、新项目现有调用方。不能复现时，至少用真实数据和调用链证明发生条件。

先判断类型：数据异常、字段语义、状态流转、查询归属、边界校验、配置、并发、外部响应、旧逻辑迁移遗漏。

- 数据结构/字段不清：先查 MCP 新旧库和样本，再决定 casts、默认值、状态和迁移
- 查询错误：修复进模型或明确仓库，不在控制器/中间件/验证器/worker 追加条件补丁
- 迁移差异：对照旧代码、旧库数据和新规则，只迁必要能力，不恢复旧目录和旧兼容字段
- 脏数据：区分代码修复和数据修复；代码只处理合理边界；数据修复要有筛选条件和回滚方案

禁止扩大兼容边界掩盖错误（同时接受 snake_case 和 camelCase、多套状态来源、默认吞外部异常）。禁止新增第二套判断、查询或状态流转；发现重复必须收敛到权威模型、字典、配置或底座。

修复后反向检查同类入口、字段、状态、表和旧项目对应功能。必须留下可验证结果：`php -l`、目标用例、最小复现、库样本或日志对比。说明必须写清根因、证据、修改位置、影响范围和验证结果，不用「可能是」「应该是」「临时处理」。

## 安全与日志

禁止把密钥、密码、Token 明文写进代码。API 密钥、AI Provider 密钥走项目统一加密方案。public 下禁止可执行 PHP 暴露运行，遵循系统安全常量。

异常、错误、系统操作日志走 `foundation/log` 和对应模型。中间件做入口校验，查询仍进模型。

## OpenAI

涉及 OpenAI 产品、模型、API、参数、响应、工具调用、流式、错误码、价格、模型升级、提示词升级时，使用 `openai-docs` 技能。以官方文档为准，优先官方 MCP；没有结果才退回官方域名搜索。禁止用非官方文章、记忆或旧项目写法当 API 事实。

禁止猜测模型名、路径、参数、响应字段、计费、默认值、废弃状态和兼容行为。改 Provider/模型配置/适配/工具调用/流式/错误处理前先查文档并记录依据。

官方文档与旧项目不一致时以官方为准。文档没覆盖则标记未确认并停止扩大实现。

模型升级保持窄范围：只改当前明确使用的默认值和直接相关提示词。提示词升级必须保留业务行为边界，不能因为新模型建议就重写权限、查询边界或异常流程。

写入注释或规则时只记录稳定约束和来源，不复制大段文档，不写未验证推断。

## 远端操作边界

默认只改本地仓库。禁止在未获**当前明确授权**时执行：`ssh` `scp` `rsync` `supervisorctl` `systemctl` `php start.php restart/stop/start`、Workerman reload、杀远端进程、重启 Webman。

「修复」「验证」「同步代码」「跑一下接口」不等于授权重启。同步授权与重启授权必须分别确认。需要远端生效时，先说明文件、是否 reload、风险和验证方式，等同意再操作。

本地 `php -l`、类型检查、命名检查不需要远端授权，但不得自动延伸为部署。

遇到「本地已改但线上仍报旧错」、命名空间不同步、类重复声明、方法签名不兼容、autoload/opcache 未刷新时，用 SSH/SFTP **核对**远端文件。只把远端当运行事实来源；修改仍先落本地再同步，避免只在线上改。

连接信息以用户当前授权和本机 SSH/MCP 配置为准，禁止把远端密码、远端绝对路径写入技能、代码或提交物。
