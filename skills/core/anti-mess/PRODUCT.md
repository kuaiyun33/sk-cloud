# 商品中心边界

把商品中心从模块混合体里拆出来。PHP 归属走 `sk-cloud-php`。路径相对仓库根，见 [WORKSPACE.md](WORKSPACE.md)。

## 阶段

账单、计价、订单快照、前台购买、用户中心**已经落地**。按现行代码维护，继续用本技能和 `sk-cloud-php` 收敛职责，不再冻结、不回退、不另起第二套。

仍禁止：

- 把模块运行资源写进商品中心（实例、实名材料、证书文件、卡密库存、商标附件、上游执行细节、支付流水）
- 为未确认需求提前建表或建字段
- 按云服务器/域名/SSL/发卡/商标复制整套商品页
- 用旧表名、旧驼峰、旧兼容入口延续旧结构

## 商品中心只回答

```text
卖什么
怎么卖
多少钱
允许谁买
购买时选什么
支付后交给谁处理
```

新增字段无法归入商品定义、售卖规则或交付接入关系时，停下来改模块归属。

## 后端

- 控制器只接收入参、调用模型或应用层、返回响应。
- 配置装配复用模型层出口，禁止在控制器拼配置类型、配置值、周期价格和作用域过滤。
- 一致性诊断放现有模型或明确领域模型，不放控制器。
- 自动修复只允许补齐空 `model_key` 和空 `delivery_module`。需要人工判断的只输出诊断项。
- 后台列表、分页、矩阵同步、批量绑定必须和页面、控制器、路由一起设计。

权威模型在 `App\model\service`：

| 规则 | 位置 |
| --- | --- |
| 商品事实源 | `Product` |
| 商品和分组 `model_key` 一致 | `Group`、`Product` |
| 接入和商品 `model_key` 一致 | `Product` |
| 配置类型归属有效模型 | `Config` |
| 配置值归属有效配置类型 | `ConfigOption` |
| 商品不能绑定其他模型配置 | 绑定关系由对应模型维护 |
| 同配置值同周期唯一 | `ConfigPrice` |

需要翻译的商品模型继承 `Fdn\database\eloquent\LangModel`，不要另起平行基类。

## 前端

同一套商品中心页面，用 `model_key` 或 `module_type` 过滤类型。

禁止：按云服务器/域名/SSL/发卡/商标复制页面；在商品管理页维护模块资源详情；长期混用 snake_case 与 camelCase；为空配置表插入演示假数据；TS 与样式写在同一个 `.vue`。

管理页可组合：顶部模型 Tabs、左侧分组、右侧列表、商品表单、接入/周期/购买规则/配置绑定抽屉。

配置页可组合：顶部模型 Tabs、左侧配置类型、右侧配置值、周期价格矩阵。

## 发布顺序

```text
先结构，后数据
先诊断，后修复
先后端底层闭环，后后台页面
管理接口、控制器、模型方法、后台页面同步开发
```

禁止：只迁移猜测数据；回滚时轻易删除已上线表和字段。

## 验收

```text
新增域名、SSL、发卡、商标是否需要复制整套逻辑？
商品中心是否出现模块资源字段？
控制器是否出现查询、分页或复杂组装？
配置表为空时页面和接口是否正常？
诊断是否能发现模型、商品、接入、绑定和周期价异常？
```

新增类型要复制商品逻辑 → 失败。只能支持云服务器 → 失败。
